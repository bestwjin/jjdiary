# jjdiary

다산이편한세상자이(경기도 남양주시 다산중앙로81번길 25) 단지 중심을 기준으로, 다산1동·다산2동 학교까지 **자동차 최적경로** 거리를 km로 보여 줍니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173` 을 열면 학교정보가 표시됩니다. 거리는 OpenStreetMap 도로망의 자동차 경로(소요 시간이 짧은 경로)이며, 직선거리나 도보 거리가 아닙니다.

`http://127.0.0.1:4173/calendar.html` 은 날짜별 글을 남기고 삭제하는 캘린더입니다. 글은 이 브라우저의 로컬 저장소에만 남습니다.
